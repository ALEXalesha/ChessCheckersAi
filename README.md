# ChessCheckersAi

Russian checkers and chess against a neural network that taught itself by playing against
itself. Rules are plain code; the network only evaluates positions inside an alpha-beta
search. Everything is numpy and PySide6, no PyTorch.

Work in progress. The Russian README (`README.ru.md`) is the main one.
