# ChessCheckersAi: план работ

Описание проекта — в `spec.md`. Задачи идут по порядку, каждая заканчивается зелёными тестами и коммитом. Образец устройства — `../TicTacToeAi`: папки `core/`, `nn/`, `train/`, `game/`, `models/`, `tools/`, `paths.py`, `offscreen.py`, `build.py`.

## Этап 1. Каркас и общее

1. **Каркас:**
   - `git init`, `.gitignore`, `.gitattributes`, LICENSE (MIT);
   - заготовки README EN/RU;
   - `requirements.txt` (numpy, PySide6), `requirements-dev.txt`, `pytest.ini`;
   - `.gitea/workflows/ci.yml` (`runs-on: windows`) и `.github/workflows/ci.yml`.
2. **Сеть на numpy:** перенести `nn/` из TicTacToeAi (dense, conv 3×3, tanh, Adam, сохранение в npz). Тесты: градиенты против численных, сохранение и загрузка.

## Этап 2. Шашки

3. **Правила русских шашек** — `core/checkers.py`: доска, генератор ходов, взятия цепочкой, турецкий удар, превращение посреди взятия, конец партии и ничьи.
   - Ручные позиции на каждое правило.
   - Вторая медленная реализация в тестах; perft обеих совпадает до глубины 8.
   - Мутационная проверка: сломать по одному правилу, тест обязан упасть.
4. **Поиск** — `core/search.py`, общий для двух игр:
   - альфа-бета с итеративным углублением;
   - таблица перестановок (Zobrist);
   - порядок ходов;
   - лимит времени;
   - остановка по флагу.
   - Тесты: находит мат или выигрыш в N ходов на собранных позициях; с оценкой по материалу совпадает с полным минимаксом на малой глубине.
5. **Боты для проверок:** случайный, жадный, альфа-бета по материалу. Турнир на N партий с зерном.
6. **Обучение шашек** — `train/selfplay.py --game checkers`: игра с собой, TD-Leaf(λ), аугментация, снимки, журнал, продолжение с места.
   - Потоки ограничены параметром.
   - Модели и паспорта — в `models/`.
   - Тесты: короткое обучение улучшает результат против случайного; паспорт пересчитывается партия в партию.

## Этап 3. Шахматы

7. **Правила шахмат** — `core/chess.py`.
   - Perft:
     - начальная позиция до глубины 5;
     - Kiwipete до глубины 4;
     - позиции 3–6 из списка Chess Programming Wiki.
   - SAN, разбор и запись FEN и PGN.
   - Мутационная проверка правил.
8. **Тихий поиск** для шахмат, книга первых ходов для разнообразия проверок.
9. **Обучение шахмат.** Сначала короткий прогон на 10–20 минут: замер скорости и решение о размере сети и числе партий. Записать в отчёт, сколько займёт полное обучение, прежде чем его запускать. Затем полное обучение, снимки уровней, паспорт.

## Этап 4. Окно (PySide6)

10. **Меню и доска:**
    - игра, режим, цвет, уровень;
    - ходы мышью, подсветка, анимация, переворот доски;
    - фигуры и шашки нарисованы своим кодом.
11. **Боковая панель:**
    - список ходов;
    - взятые фигуры;
    - «Мысли сети»;
    - отмена хода;
    - превращение пешки;
    - сохранить и открыть PGN.
12. **Режимы:** вдвоём за одним ПК, сеть против сети с паузой и скоростью. Поиск в отдельном потоке, окно не подвисает (тест: во время хода сети окно отвечает).
13. **Оформление и настройки:**
    - статистика;
    - темы Paint (светлая и тёмная);
    - RU/EN;
    - window-state.

    Ловушки Qt — по памяти (qt-wrapped-label-height, qt-combo-dropdown).
14. **Тесты окна** offscreen, снимки экранов для README: обе игры, обе темы, «Мысли сети».

## Этап 5. Выпуск 1.0.0 (только после «да» Алексея)

15. **Независимая проверка** кода и внешнего вида другим агентом, исправления, поиск личного по всему дереву.
16. **Документы:**
    - README EN/RU с цифрами из паспортов и скриншотами;
    - CHANGELOG, заметки к выпуску.
17. **Сборка:** `build.py` (PyInstaller без лишнего), установщик NSIS, portable zip. Поставить у Алексея, старые сборки — в Корзину, отчёт о месте на диске.
18. **Публикация:**
    - Gitea, потом GitHub через `tools/publish_github.sh`. Первый коммит GitHub с LICENSE и README заменяется историей Gitea;

    - описание и темы репозитория.

## Примерный объём

- этапы 1–2 — около дня;
- этап 3 — день или больше: главное время уходит на обучение шахмат, а сколько именно, покажет замер в задаче 9;

- этап 5 — пара часов.
