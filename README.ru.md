# ChessCheckersAi

Русские шашки и шахматы против нейросети, которая научилась играть сама с собой. Правила
написаны обычным кодом, сеть только оценивает позиции внутри поиска альфа-бета. Всё на
numpy и PySide6, без PyTorch.
